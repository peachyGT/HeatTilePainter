Heat Tile Painter stores images added with Browse / Add custom in UserTextures and records their
generated IDs in UserTextures.cfg. Craft files do not contain the original path from your PC.

Do not redistribute this folder without checking the licenses of the images you imported.

For a distributable texture pack, use a HEAT_TILE_TEXTURE config node instead. A copyable example
is in ../CustomTextures.cfg.example and the complete field reference is in the source repository at
docs/CUSTOM-TEXTURES.md.
